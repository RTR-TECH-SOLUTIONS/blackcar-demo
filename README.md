# Transfer Otopeni — demo de prezentare

Export static al site-ului de prezentare (transferuri aeroport, tururi
private și ghid de destinații), construit de RTR Tech Solutions.

- **Preview live:** https://rtr-tech-solutions.github.io/blackcar-demo/
- Sursa reală e o temă WordPress bloc (`carpathia`); folderul acesta e doar
  snapshot-ul static publicat pentru client, regenerat cu `tools/build-demo.sh`.
- Textele, prețurile și fotografiile sunt orientative, pentru prezentare.
- Tot site-ul e `noindex, nofollow` cât timp e demo.

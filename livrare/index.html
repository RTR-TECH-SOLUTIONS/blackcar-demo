Pachet de instalare pentru WordPress

Site-ul e o temă WordPress bloc, fără pluginuri și fără page builder. Merge pe orice găzduire cu WordPress 6.5 sau mai nou.

  • INSTALARE.md pașii de instalare, în ordine
  • carpathia.zip tema, se încarcă din Aspect → Teme
  • continut.xml paginile, tururile, articolele și imaginile, pentru Unelte → Import
